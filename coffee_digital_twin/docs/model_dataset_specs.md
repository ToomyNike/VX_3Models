# 云南小粒咖啡 A-H-B 协同智能决策系统 —— 数据集字典与梳理

本文档梳理了系统中集成的三个核心机制模型（APSIM、HYDRUS-1D、BEPS-Lite）的数据输入输出详情，包含变量名、单位、时间周期等，供后续制作标准数据集参考。

---

## 1. APSIM-Coffee 作物生长模型（作物层）
**核心职责：** 模拟咖啡树的长期生长、物候发育、生物量积累及最终产量预测。
**时间周期（步长）：** 天（Daily），可模拟跨年度生命周期（系统中按多年生进行连年计算）。

### 输入数据 (Inputs)
| 数据维度 | 字段名称 | 单位 | 周期/类型 | 数据说明 |
| :--- | :--- | :--- | :--- | :--- |
| **地块基础** | `tree_age` | 年 (years) | 静态配置 | 树龄，动态推算播种年份和当前生长期 |
| **地块基础** | `elevation_m` | 米 (m) | 静态配置 | 海拔高度 |
| **气象驱动** | `radiation_mj` | MJ/m²/day | 日均 (Daily) | 太阳辐射量 |
| **气象驱动** | `maxt` / `mint` | ℃ | 日均 (Daily) | 最高温与最低温 |
| **气象驱动** | `rain_mm` | mm/day | 日均 (Daily) | 日降雨量 |
| **农事操作** | `irrigation` | mm | 事件型 (Event) | 灌溉事件时间及水量（系统自动换算为 mm） |
| **农事操作** | `fertilization`| kg/ha | 事件型 (Event) | 施肥事件时间及施氮量（系统自动换算为 kg/ha 的 NO3N） |

### 输出数据 (Outputs)
| 数据维度 | 字段名称 | 单位 | 类型 | 数据说明 |
| :--- | :--- | :--- | :--- | :--- |
| **核心指标** | `yield_pred_kg_mu` | kg/亩 | 预测值 | 当前管理和气象下的预期亩产量 |
| **生长状态** | `stage` | Enum | 当前状态 | 当前所处生育期（如：果实膨大期） |
| **生长状态** | `lai` | m²/m² | 当前状态 | 叶面积指数 (LAI) |
| **生物量** | `biomass_kg_ha` | kg/ha | 累积值 | 总生物干物质积累量 |
| **环境胁迫** | `water_stress` | 无量纲(0-1)| 当前状态 | 水分胁迫指数（0表示无胁迫，接近1为严重胁迫）|
| **环境胁迫** | `nitrogen_status`| Enum | 当前状态 | 氮素状态（正常/偏低/不足） |
| **时间序列** | `yield_curve` | kg/亩 | 序列 (Series)| 随时间推移的产量演变曲线 |

## 2. HYDRUS-1D 土壤水分模型（土壤层）
**核心职责：** 模拟土壤水分在一维垂直剖面上的运动（入渗、蒸发、吸水），精确掌握根区水分动态。
**时间周期（步长）：** 天（Daily），系统运行时计算指定任务窗口期内的水分变化。

### 输入数据 (Inputs)
| 数据维度 | 字段名称 | 单位 | 周期/类型 | 数据说明 |
| :--- | :--- | :--- | :--- | :--- |
| **土壤物理参数**| `SELECTOR.IN` / `PROFILE.DAT` | 综合 | 静态模板 | 预设土壤类型、深度、van Genuchten参数等 |
| **大气边界条件**| `rain_mm` | mm/day | 日均 (Daily) | 日降雨量（转换为 cm/day 参与运算） |
| **大气边界条件**| `irrigation_mm`| mm/day | 日均 (Daily) | 日灌溉量（转换为 cm/day 参与运算） |
| **大气边界条件**| `potential_evaporation_mm` | mm/day | 日均 (Daily) | 潜在土壤蒸发量 |
| **大气边界条件**| `potential_transpiration_mm` | mm/day | 日均 (Daily) | 潜在植被蒸腾量 |

### 输出数据 (Outputs)
| 数据维度 | 字段名称 | 单位 | 类型 | 数据说明 |
| :--- | :--- | :--- | :--- | :--- |
| **核心指标** | `root_uptake_ratio`| 无量纲(0-1)| 当前状态 | 根系实际吸水与潜在吸水比值（越近1越好） |
| **核心指标** | `infiltration_depth_cm` | cm | 当前状态 | 湿润锋下移深度（水分入渗深度） |
| **水分状态** | `water_status` | Enum | 当前状态 | 综合评价（水分适宜/轻度偏干/中度干旱/重度干旱） |
| **剖面含水率** | `soil_profile_current`| cm³/cm³ | 空间分布 | 不同深度(10,20,40,60,100cm)的体积含水率(theta) |
| **时间序列** | `soil_moisture_series`| cm³/cm³ | 序列 (Series)| 核心根层（d10,d20,d40,d60）含水率时间演变 |

## 3. BEPS-Lite 冠层生态模型（冠层层）
**核心职责：** 模拟冠层光合作用和生态学特征，计算总/净初级生产力（GPP/NPP），用于长势评分和风险预警。
**时间周期（步长）：** 天（Daily），根据最新气象及多模型耦合因子实时计算。

### 输入数据 (Inputs)
| 数据维度 | 字段名称 | 单位 | 周期/类型 | 数据说明 |
| :--- | :--- | :--- | :--- | :--- |
| **气象驱动** | `radiation_mj` | MJ/m²/day | 日均 (Daily) | 太阳辐射量 |
| **气象驱动** | `tmax` / `tmin` | ℃ | 日均 (Daily) | 最高温与最低温 |
| **气象驱动** | `wind_ms` | m/s | 日均 (Daily) | 日均风速 |
| **遥感/耦合因子**| `lai` | m²/m² | 当前状态 | 叶面积指数（**由 APSIM 耦合提供**） |
| **遥感/耦合因子**| `ndvi` | 无量纲(0-1)| 当前状态 | 归一化植被指数 |
| **遥感/耦合因子**| `shade_degree` | 无量纲(0-1)| 当前状态 | 咖啡园遮阴度（轻度/中等/重度，影响辐射到达）|
| **遥感/耦合因子**| `water_factor` | 无量纲(0-1)| 当前状态 | 水分限制因子（**由 HYDRUS 提供**的根系吸水效率）|

### 输出数据 (Outputs)
| 数据维度 | 字段名称 | 单位 | 类型 | 数据说明 |
| :--- | :--- | :--- | :--- | :--- |
| **核心指标** | `growth_score` | 分 (0-100) | 当前状态 | 综合 GPP、水分、温度等因素生成的长势评分 |
| **核心指标** | `beps_risk` | Enum | 当前状态 | 冠层生态风险等级（低/中等/高风险） |
| **生产力** | `gpp_today` | gC/m²/day | 日均值 | 总初级生产力 (Gross Primary Productivity) |
| **生产力** | `npp_today` | gC/m²/day | 日均值 | 净初级生产力 (Net Primary Productivity) |
| **蒸散发** | `et_today` | mm/day | 日均值 | 冠层日蒸散发量 (Evapotranspiration) |
| **碳汇** | `carbon_sink_kgC_mu`| kgC/亩 | 累积值 | 咖啡园固碳量计算结果 |
| **时间序列** | `gpp_series` 等 | 多种 | 序列 (Series)| GPP、NPP、ET 的时间演变序列 |

## 4. 模型间数据耦合 (Data Fusion)
您的系统通过后端 `api/fusion_engine.py` 及相关服务进行了精妙的耦合，制作数据集时请注意这种**因果关系**：
1. **APSIM** 生成的 `lai` (叶面积指数) $\rightarrow$ 传递给 **BEPS-Lite** 用于估算冠层光合效率 (FPAR)。
2. **HYDRUS-1D** 计算出的物理级 `root_uptake_ratio` (根系吸水效率) $\rightarrow$ 传递给 **BEPS-Lite** 作为极其重要的 `water_factor` 限制光合作用。
3. **LLM Agent** (GLM-4-Flash) 接收上述三个模型的所有核心输出，生成 `why` 与 `model_basis`，为前端提供可解释的农业建议。
