# 接口字段说明

## GET /api/ping

测试前后端连通。

## POST /api/plot/init

建园初始化。核心字段：

- `plot_name`
- `area_mu`
- `tree_age`
- `coffee_variety`
- `latitude`
- `longitude`
- `elevation_m`
- `soil_type`
- `shade_level`

## POST /api/farmop/add

农事打卡。核心字段：

- `plot_id`
- `op_type`: `irrigation` / `fertilization` / `canopy_management` / `damage_report`
- `date`
- `amount`
- `unit`
- `fertilizer_type`
- `operation_type`
- `severity`
- `remark`

## POST /api/model/run

运行三模型并返回统一结果。

```json
{
  "plot_id": "plot_001",
  "scenario": {
    "scenario_name": "当前管理方案",
    "extra_irrigation_mm": 0,
    "extra_fertilizer_kg_mu": 0
  }
}
```

## GET /api/model/status/<task_id>

查询模型任务状态。

## GET /api/model/result/<task_id>

查询模型融合结果。

## GET /api/dashboard

首页仪表盘数据。

## POST /api/advice/generate

生成 what / how / why 三段式农技建议。
